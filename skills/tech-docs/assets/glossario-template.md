# Glossário

> Termos técnicos e siglas utilizados nesta documentação.

| Termo / Sigla | Definição |
|---------------|-----------|
| ACK | AWS Controllers for Kubernetes — operadores K8s que gerenciam recursos AWS via CRDs |
| ArgoCD | Ferramenta de GitOps para entrega contínua declarativa em Kubernetes |
| BACEN | Banco Central do Brasil |
| CRD | Custom Resource Definition — extensão da API do Kubernetes |
| EKS | Amazon Elastic Kubernetes Service |
| GitOps | Modelo operacional que usa Git como fonte de verdade para infraestrutura e aplicações |
| IAM | AWS Identity and Access Management |
| IRSA | IAM Roles for Service Accounts — integração IAM com K8s ServiceAccounts no EKS |
| kro | Kubernetes Resource Orchestrator — orquestrador de recursos compostos no K8s |
| LGPD | Lei Geral de Proteção de Dados |
| mTLS | Mutual TLS — autenticação mútua via certificados |
| PCI-DSS | Payment Card Industry Data Security Standard |
| PIX | Sistema de pagamentos instantâneos do Banco Central do Brasil |
| RACI | Responsible, Accountable, Consulted, Informed — matriz de responsabilidades |
| RTO | Recovery Time Objective — tempo máximo aceitável de indisponibilidade |
| RPO | Recovery Point Objective — perda máxima aceitável de dados |
| SLA | Service Level Agreement |
| VPC | Virtual Private Cloud |
